# ECLIPSE UI/UX Principles

- Three primary destinations only: Model Intelligence & Inference Platform, Capability Amplification & Knowledge System, and ECLIPSE Agent.
- The Agent is easy to find and behaves as the everyday conversational workspace.
- The visual system should be polished, colourful and spacious, with restrained navy/dark surfaces and clear cyan accents as a direction, not a requirement to show a dense sci-fi dashboard everywhere.
- Beginner workflows use plain language, short steps, friendly progress and understandable errors.
- Default screens show only useful state. Tensor maps, resource telemetry, advanced controls and experiment details are progressively disclosed.
- No decorative metrics or fake buttons. Every control must do something real or be clearly marked unavailable during development.
- Preserve keyboard navigation, readable contrast, scalable text, focus visibility and light/dark themes.
- Show what the Agent is doing, what files/tools it can access, and which actions need approval.
- Give the user a prominent stop control and clear task status when work is running.
