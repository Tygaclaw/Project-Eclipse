# ECLIPSE Complete Starter Kit

**Purpose:** This package is the single handoff bundle for beginning the new ECLIPSE build in a fresh ChatGPT conversation.

**What to do:** Upload this ZIP archive to a new ChatGPT conversation and send the one-word instruction **GO**. ChatGPT should read `START_HERE.md`, follow `MASTER_EXECUTION_PROMPT.md`, inspect the five original source documents, verify GitHub access, and begin the project step by step.

## Important project definition

ECLIPSE is one unified, Windows-first AI ecosystem with three primary user-facing workspaces:

1. **Model Intelligence & Inference Platform** — the original model-intelligence/model-engineering workstream: inspect models before running them, create the Model Atlas, assess feasibility, prepare and transform models, investigate compression, predictive weight/expert prefetching, and optimize supported inference paths.
2. **Capability Amplification & Knowledge System** — the original Qwen capability-amplification workstream: planning, research/context, tools, execution, verification/recovery, persistent correction memory, skills, Obsidian, and measurable capability improvements.
3. **ECLIPSE Agent** — a complete ChatGPT/Claude-like conversational desktop experience that uses connected models and can act as the user's practical AI agent, with safe tool use, code execution, files, research, GitHub, project context, memory, and access to the other two workspaces.

All three are connected by the shared ECLIPSE Core. The first two workspace labels summarize the two workstreams explicitly described in the historical unified handoff. The original Master Plan's five technical subsystems remain internal architectural components; do not discard them.

## Visual design is a product requirement

The previous crowded dashboard concept was rejected. ECLIPSE must be colourful, lively, polished, spacious and beginner-friendly. The default screens must show only the few things needed for the current task. Use progressive disclosure for advanced controls and diagnostics. Do not fill the screen with cards, charts, statistics or technical jargon. The Agent should feel familiar and welcoming, like a high-quality conversational AI application.
